# Надежда Иванова — портфолио

Одностраничный сайт-портфолио/резюме. Чистый **HTML + CSS + JavaScript**, без библиотек и сборки.
Вёрстка по принципу **Mobile First**: базовые стили написаны для телефона, а `@media (min-width: 768px)`
и `@media (min-width: 1100px)` добавляют планшетную и десктопную раскладку.

- Сайт: https://e1ova00.github.io/nadezhda-ivanova-portfolio/
- Репозиторий: https://github.com/e1ova00/nadezhda-ivanova-portfolio
- Шрифты: Inter Tight + JetBrains Mono (Google Fonts, open source)

## Концепция — «Невесомый архив»

Сайт устроен как световой стол дизайнера: строгая швейцарская сетка, индексы и технические подписи —
и работы, которые ведут себя как физические предметы с очень маленькой массой. Интерфейс почти
бесцветный (off-white, холодный серый, графит), цвет появляется только через сами проекты.
Принцип: 70 % строгой editorial-структуры + 30 % контролируемого хаоса.

## Структура

```
index.html            — вся страница
css/style.css         — стили (Mobile First)
js/                   — по одному файлу на эффект
images/portrait.jpg   — портрет
projects/fashion/     — скриншоты проекта 01   (см. README.txt в папке)
projects/web-app/     — скриншоты проекта 02
video/                — video-01..03.mp4 + poster-01..03.jpg
photography/          — photo-01..08.jpg
charity/              — charity-01..02.jpg
```

Пока файла нет, на его месте серая заглушка с путём. Чтобы заменить — просто положи файл
с этим именем в нужную папку. Текстовые заглушки в `index.html` помечены квадратными скобками `[…]`
и классом `todo`.

## Реализованный функционал на JavaScript

| Эффект | Файл |
|---|---|
| Кастомный курсор со сглаживанием и хвостом, меняет роль: VIEW / DRAG / PLAY / OPEN | `js/cursor.js` |
| Магнитные кнопки и ссылки (только компактные элементы) | `js/magnetic.js` |
| Intro: буквы имени выезжают по очереди, затем портрет; буквы реагируют на близость курсора | `js/intro.js` |
| Появление блоков и построчное появление текста (IntersectionObserver, один раз) | `js/reveal.js` |
| Параллакс по `data-speed`, горизонтальный дрейф заголовков, индекс разделов | `js/scroll-fx.js` |
| Хедер: сжимается, прячется вниз / появляется вверх; часы Санкт-Петербурга | `js/header.js` |
| «Шторка» при переходе по меню | `js/curtain.js` |
| **Signature:** «парящая» композиция изображений с пружинной физикой и инерцией | `js/float.js` |
| 3D-карусель (coverflow): стрелки, клавиатура, драг/свайп с порогом, счётчик 01 / 06 | `js/coverflow.js` |
| Переход между двумя слоями по прогрессу скролла (desktop → mobile) | `js/crossfade.js` |
| Flip-карточки (разворот на 180°) | `js/flip.js` |
| Видео: беззвучное превью при наведении, раскрытие на весь экран через clip-path | `js/video.js`, `js/modal.js` |
| Фото-архив: стопка разлетается по скроллу, перетаскивание, skew при быстром скролле, просмотр | `js/sheet.js` |
| Подвал реагирует на мышь | `js/footer.js` |
| Ленивая загрузка изображений и заглушки | `js/placeholders.js` |

Общие правила: анимируются только `transform`, `opacity` и `clip-path`; при `prefers-reduced-motion`
всё сводится к мгновенному конечному состоянию; курсор и магнитные эффекты отключены на тач-устройствах
(`pointer: coarse`); горизонтального скролла на мобильных нет.

## Использование AI

**Инструмент:** Claude Code (Anthropic).

**Для каких задач:**
1. Исследование и концепция — анализ ТЗ и визуальных референсов, формулировка концепции,
   выбор шрифтов, сетки и 5 главных взаимодействий.
2. Реализация — вёрстка по Mobile First и JS-эффекты.
3. Ревью — автоматическая проверка в браузере (Playwright): скриншоты на 1440×900 и 390×844,
   проверка ошибок в консоли и горизонтального переполнения.

**Существенный запрос** (сокращённо):
> «Сделай на чистом HTML/CSS/JS (без библиотек вроде GSAP) набор анимаций для лендинга: кастомный курсор
> с хвостом, магнитные элементы, анимация появления букв в заголовке (после анимации зафиксировать
> финальное состояние отдельным классом), scroll-reveal блоками, скролл-зависимый переход между двумя слоями,
> 3D-карусель, flip-карточки, поведение хедера, шторка переходов. Только transform/opacity,
> prefers-reduced-motion, отключение hover-эффектов на touch, без горизонтального скролла».

**Результат проверки:**
- На первых скриншотах почти все блоки с `data-reveal` оставались невидимыми. Причина — специфичность
  CSS: правило «скрыть» `.js [data-reveal]:not(…):not(…)` оказалось сильнее правила «показать»
  `.js [data-reveal].is-visible`. Исправлено: у правила «показать» такая же цепочка селекторов.
- Боковой индекс разделов налезал на подписи первого экрана и на стрелки карусели — индекс скрыт на
  первом экране, стрелки карусели перенесены вправо.
- Крупные заголовки при горизонтальном «дрейфе» уезжали за левый край — направление дрейфа изменено.
- После добавления реальных скриншотов проверка снова нашла горизонтальный скролл (+83 px на десктопе):
  дрейфующие заголовки и вертикальные слайды карусели выходили за правый край. Исправлено через
  `overflow-x: clip` на `main` — он обрезает лишнее, но не ломает sticky-блоки.
- Картинки с появлением через маску (`clip-path`) не появлялись никогда: IntersectionObserver считает
  полностью обрезанный элемент невидимым. Исправлено: наблюдаем за родительским блоком, а класс ставим картинке.
- Горизонтальное переполнение: 0 px на десктопе и на мобильном. Ошибок в консоли нет.

**Что я исправила самостоятельно:**
- *[ЗАПОЛНИТЬ: что поменяла руками — тексты, размеры, расположение фото, цвета, порядок разделов и т.д.]*

Персональные данные, пароли и токены AI-сервису не передавались (кроме имени и портрета,
которые и так публикуются на сайте).

## Как посмотреть локально

Открой `index.html` двойным кликом — сайт работает и без сервера.
Видео-превью надёжнее проверять через сервер: в папке проекта выполнить
`python3 -m http.server 8000` и открыть `http://localhost:8000`.
